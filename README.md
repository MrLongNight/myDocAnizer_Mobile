Smart Document Scan and Management App for Android.

## Overview

myDocAnizer Mobile is a modern Android app for scanning, organizing, and securely managing documents. It is designed to make everyday paperwork easier by combining fast capture workflows, document search, and secure local storage in one streamlined mobile experience.
